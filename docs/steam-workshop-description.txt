Tell Claude "keep my beavers alive and get to 77 wellbeing" and watch it figure out the rest. It reads your colony, places buildings, routes paths up cliffs, manages workers, and reacts to droughts. You play together.

[code]
1. pipx install timberbot
2. tbot watch   (leave running in a terminal)
3. Press Launch in the in-game Timberbot widget
[/code]

You need Python 3.10+ and a one-line install (`pipx install timberbot`). After that, `tbot watch` opens a long-lived WebSocket to the mod and dispatches your chosen agent (Claude / Codex / OpenCode / a custom CLI). The in-game widget owns the **Launch / Stop** gate — until you press Launch, the mod refuses every `/api/*` call except the connector handshake. Stop closes the gate instantly when you want to take over manually.

[h1]What can the AI actually do[/h1]
It sees everything you see. Every beaver's position, needs, and workplace. Every building's workers, power, inventory, and recipes. The full map with terrain, water, trees, and what's occupying each tile.

It can place and demolish buildings, route paths with auto-stairs across elevation changes, assign workers, manage crops and trees, control floodgates, adjust stockpiles, unlock science, and change game speed. All through the same validation the game uses when you place things by hand.

[code]
tbot brain
tbot top
tbot place_path x1:0 y1:0 x2:200 y2:180
tbot map x1:110 y1:130 x2:130 y2:150
[/code]

Ask it to build a lumber district and it will find valid spots near trees, place the buildings, connect paths back to the district center, and assign workers. Ask it to prepare for drought and it will check water reserves, adjust production, and build storage.

[h1]Not just for AI[/h1]
The whole thing is an HTTP + WebSocket API. You can write your own scripts, build dashboards, or hook it into whatever you want. About 70 game events stream over the WebSocket (`tbot listen` or any WS client) so your code reacts to droughts, deaths, construction, and weather without polling. There's a Python client included, but anything that speaks HTTP + WebSockets works.

[h1]Getting started[/h1]
1. Subscribe and enable in Mod Manager
2. Install the CLI: [code]pipx install timberbot[/code]
3. Run [code]tbot watch[/code] in a terminal and leave it running
4. Start a game and press Launch in the Timberbot widget

Works with Claude Code, OpenAI Codex, OpenCode, or any CLI agent that can be invoked from `tbot watch`. See the [url=https://impuls42.github.io/timberbot/getting-started/]full setup guide[/url] for details.
